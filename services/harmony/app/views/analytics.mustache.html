    Relative times

    A timestamp or date parameter can be a time relative to when the query runs, instead of a fixed time. It's saved as written, so a saved query or dashboard using now-7d always covers the 7 days before it runs. Times are in UTC.

    Syntax

    • now is the time the query runs.
    • - or + a number and a unit moves the time: now-7d, now+1h.
    • / and a unit rounds down to the start of that unit: now/d is midnight today.
    • The units are s seconds, m minutes, h hours, d days, w weeks (starting Monday), M months and y years. Note that m is minutes and M is months.
    • Steps apply left to right: now/d-1h is 11pm yesterday (midnight, then back an hour), while now-1h/d is the start of the day it was an hour ago.

    Examples

    ExpressionMeansRight now
    nowThe time the query runs
    now-15m15 minutes ago
    now-24h24 hours ago
    now-7d7 days ago

    Ranges

    For a range, write the query as created_at >= $start AND created_at < $end, so each end is the start of the next period.
