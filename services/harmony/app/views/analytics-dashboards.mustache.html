    A title can show the panel's parameter values, using the names of its query's parameters (listed under each title). For a query with a $start parameter: $start shows its value in words (now-7d is "7 days ago"), ${start:raw} shows it as written ("now-7d"), and $__range shows the time range from $start to $end, or to now if there's no end parameter ("the last 7 days"). So "Errors in $__range" stays right whatever the range is set to. A blank title is the query's name.
